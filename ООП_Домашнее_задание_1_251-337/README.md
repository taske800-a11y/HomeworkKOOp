## Описание выполненной работы

Тема занятия: классы, объекты, поля и методы, конструкторы, обращение к функциональности класса.

- **Задание 1 (индивидуально)** — доработать класс `Book`: главный конструктор `(title, author, year)`; упрощённый конструктор `(title)` через `: this(title, "неизвестен", 0)`; создание книги через инициализатор объекта; `Deconstruct(out string title, out bool isRead)` и распаковка книги.
- **Задание 2 (индивидуально)** — дополнить `StudentBookStorage` методом `PutABook`: неопределённую книгу (`null`) разместить нельзя; разместить книгу может только владелец хранилища (если он определён) — логика доступа та же, что у `GetABook` (`IsValidAccess`). Продемонстрировать размещение и извлечение.
- **Задание 3 (групповое)** — классы «почти из жизни»: `User`, `CommunicationChannel`, `Contact`, `UserProfile` и демонстрационная компоновка в `Program.cs`.

### Задание 3 (групповое)

| Класс | Поля | Автор |
|---|---|---|
| `User` | ID, ФИО, логин, пароль | Лукьянцев |
| `Contact` | ID, ID канала связи, идентификатор в канале | Чулков |
| `CommunicationChannel` | ID, имя канала | Лохмаев |
| `UserProfile` | пользователь, список контактов | Останин |
| `Program` (компоновка и демонстрация) | — | Лохмаев |

`Program.cs` создаёт три канала связи (Email, Telegram, Телефон), пользователя и три его контакта, собирает `UserProfile`, выводит профиль, контакты с названиями каналов и краткую статистику. Статистика получается через **деконструктор** `UserProfile.Deconstruct(out User user, out int contactsCount)`.

### Задания 1 и 2 (индивидуальные)

Каждый участник выполнил оба задания самостоятельно; ожидаемый вывод каждой программы приведён в README соответствующей папки. Во всех работах:

- созданы книги главным и упрощённым конструкторами и через инициализатор объекта;
- книга распакована через `Deconstruct`;
- `PutABook` возвращает `false` для `null`-книги, для чужого студента и для `null`-студента, и `true` для владельца (в «ничейное» хранилище может класть любой студент).
