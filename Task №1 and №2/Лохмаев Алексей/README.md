# Индивидуальные задания 1 и 2

## Состав проекта
- `Book.cs` — класс книги, основной и упрощённый конструкторы, деконструктор.
- `Student.cs` — класс студента.
- `StudentBookStorage.cs` — хранилище книги с проверкой доступа.
- `Program.cs` — демонстрация выполнения заданий 1 и 2.
- `Zadaniya1i2.csproj` — файл проекта .NET 8.

## Запуск
Откройте `Лохмаев Алексей.csproj` в Visual Studio и запустите проект, либо из терминала выполните:

```bash
dotnet run
```

## Что демонстрируется
1. Создание книги основным конструктором.
2. Инициализация свойства `IsRead` через инициализатор объекта.
3. Создание книги упрощённым конструктором.
4. Деконструкция книги в название и статус прочтения.
5. Успешное размещение книги владельцем.
6. Запрет размещения книги другим студентом.
7. Получение книги владельцем.
8. Запрет размещения `null`.
