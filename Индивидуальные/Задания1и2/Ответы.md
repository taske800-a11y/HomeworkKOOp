# Задание 2

1. `private int age;` — поле доступно только внутри класса.
2. `internal class Student { }` — тип доступен внутри текущей сборки, но не из другой сборки.
3. `file class PriceFormatter { }` — вспомогательный тип доступен только в этом файле.
4. `protected void Validate() { }` — метод доступен внутри класса и его наследников.
5. Унаследоваться от типа с модификатором `file` нельзя, потому что такой тип виден только в исходном файле.
6. Нарушен принцип **DIP** (Dependency Inversion Principle): `Catalog` напрямую создаёт конкретную реализацию репозитория вместо зависимости от абстракции.
7. Нарушен принцип **SRP** (Single Responsibility Principle): `Product` отвечает сразу за хранение данных, сохранение в файл и печать отчёта.
