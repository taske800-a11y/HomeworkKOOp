- `Program.cs` — демонстрация обоих индивидуальных заданий и краткие ответы на теоретические вопросы.
- `IndividualLokhmaev.csproj` — отдельный запускаемый проект на .NET 10.

## Задание 1. Auditorium

Реализована структура `Auditorium` с полями номера аудитории, корпуса и количества мест.

В программе отдельно показаны:

1. создание аудитории основным конструктором;
2. создание значения через `default` и значения полей по умолчанию;
3. независимость исходной структуры и копии после обычного присваивания;
4. создание копии с помощью `with`;
5. отличие передачи структуры по значению от передачи через `ref`;
6. вывод описания аудитории методом `Show`.

Для примера выбрана лаборатория `3D-204` в корпусе ИСИТ. Упрощённый конструктор принимает только номер и вызывает основной конструктор через `this`, подставляя корпус «Главный корпус» и нулевое количество мест.

## Задание 2. Класс и структура

Для сравнения использованы отдельные типы, не повторяющие примеры других участников:

- `WorkshopStudent` — класс. Две переменные указывают на один объект; изменение через вторую переменную видно и через первую.
- `EnrollmentCard` — структура. После копирования изменение семестра в копии не меняет исходный экземпляр.
- `EquipmentLabel` — дополнительный пример структуры со ссылочным полем `List<string>`. При копировании структуры копируется ссылка на список, поэтому изменения общего списка видны через оба экземпляра.

В конце программы приведены ответы о размещении объекта класса и локального `int`, достижимости объектов для сборщика мусора и поверхностном копировании ссылочных полей.

## Что важно при проверке

В выводе нужно обратить внимание на три разных ситуации:

- `valueCopy` и `withCopy` изменяются независимо от исходной `Auditorium`;
- `firstReference` и `secondReference` работают с одним объектом класса;
- `originalLabel` и `copiedLabel` — разные значения структуры, но их поле `Tags` содержит ссылку на один список.

Таким образом, пример со `List<string>` показывает, почему копирование структуры не означает рекурсивного копирования всех объектов, на которые ссылаются её поля.
